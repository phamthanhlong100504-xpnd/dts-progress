# Tài liệu DTS Progress

Đọc [LOCAL_SETUP.md](LOCAL_SETUP.md) để cấu hình môi trường/migration, [PROGRESS_FEATURES.md](PROGRESS_FEATURES.md) để nắm nghiệp vụ và [api-blueprint/README.md](api-blueprint/README.md) để nối dữ liệu.

Tài liệu mô tả code local đang bàn giao trên nhánh feature/progress-backend-completion: dashboard/chapter legacy, phiên chuẩn Practice, projection câu hỏi và learning overview. [db/MIGRATION_CATALOG.md](db/MIGRATION_CATALOG.md) giải thích V1–V3 và điều kiện trước khi nâng cấp.

Không sao chép secret từ environment vào Git; .env.example là mẫu và không tự nạp vào tiến trình. Quá trình chuẩn bị Git chỉ viết tài liệu/quy tắc đóng gói, giữ nguyên Java/YAML/SQL đã có.
